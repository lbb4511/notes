## 📋 技术依赖关系

| 技术 | 前置知识 | 相关技术 |
|------|---------|---------|
| Spring Boot | Java, Maven | Spring, Tomcat |
| Spring Cloud | Spring Boot, HTTP | Eureka, Ribbon, Feign |
| Docker | Linux, 网络 | Containerd, Kubernetes |
| Kubernetes | Docker, Linux | etcd, Prometheus |
| Go微服务 | Go语言, HTTP | gRPC, etcd |

## 🎯 学习建议

1. **先基础后框架**: 掌握语言基础再学习框架
2. **先单体后微服务**: 理解单体应用再拆分微服务
3. **先容器后编排**: 会用Docker再学Kubernetes
